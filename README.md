# 🎥 VLM TemporalQA LoRA/QLoRA Video Training

An end-to-end **VideoMarathon Temporal Reasoning Pipeline** for temporal video analysis using Vision-Language Models.

This project focuses on fine-tuning, optimized inference, and automated evaluation for video question-answering tasks.

---

## 📌 Overview

The goal of this project is to build a VLM-based pipeline that can understand temporal events in videos and answer questions based on video context.

It is designed for:

* Temporal video reasoning
* Video question answering
* VLM fine-tuning
* Efficient model inference
* Automated evaluation

---

## 🔄 Workflow

```text
VideoMarathon Dataset
→ Video Preprocessing
→ Qwen2-VL-2B Fine-Tuning
→ QLoRA Optimization
→ vLLM Inference
→ Automated Evaluation
→ Comparative Performance Analysis
```

---

## ✨ Key Features

* Fine-tuned **Qwen2-VL-2B** for temporal video reasoning
* Used **QLoRA** for efficient low-resource fine-tuning
* Optimized inference using **vLLM**
* Built automated evaluation pipeline on the **VideoMarathon dataset**
* Added comparative performance analysis
* Engineered for efficient execution on **T4 GPU hardware**
* Supports end-to-end video reasoning experiments

---

## ⚙️ How It Works

1. VideoMarathon dataset is prepared for temporal video reasoning.
2. Video samples and question-answer pairs are processed.
3. Qwen2-VL-2B is fine-tuned using QLoRA.
4. vLLM is used to improve inference efficiency.
5. Model outputs are evaluated using an automated evaluation matrix.
6. Results are compared to analyze performance improvements.
